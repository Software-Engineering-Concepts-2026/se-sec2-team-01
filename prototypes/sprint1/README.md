# Lab 4 — การสร้างต้นแบบอย่างรวดเร็วด้วย Generative AI

> **โปรเจกต์ Good Night — แอปพลิเคชันติดตามการนอนหลับ**

---

## 📌 ภาพรวม

ทีม "Need to rest" สร้างต้นแบบเชิงโต้ตอบ **3 เวอร์ชัน** สำหรับฟีเจอร์ Sprint 1 ของแอปพลิเคชัน Good Night ได้แก่:
1. การตั้งค่าเป้าหมายการนอน (Adisak)
2. การติดตามปัจจัยที่ส่งผลต่อการนอน (Danudet)
3. หน้าแสดงผลข้อมูลการนอน (Rungrawi)

ทั้ง 3 ต้นแบบเป็น **PROTOTYPE ที่ทิ้งได้** (ไม่ใช่ Tracer Bullet) ใช�� HTML/CSS/JavaScript บริสุทธิ์ โดยไม่ใช้ Framework เหมือน React/Vue

**คุณสมบัติที่ทำขึ้นมา:**
- ✅ เลือกอายุจากรายการแบบเลื่อนลง (20-22 ปี)

- ✅ เลือกกิจกรรมก่อนนอนได้หลายรายการ (ดื่มกาแฟ ใช้โทรศัพท์ ออกกำลังกาย ฯลฯ)
- ✅ ปุ่มบันทึกที่บันทึกข้อมูลลงใน localStorage (หน่วยเก็บข้อมูลของเบราว์เซอร์)
- ✅ แจ้งให้ผู้ใช้ทราบเมื่อบันทึกสำเร็จ

**ความเป็นโต้ตอบ (Interactivity):**
- นาฬิกาอัปเดตแบบเรียลไทม์เมื่อเปลี่ยนเวลา
- ติ๊กข้อมูลบนกิจกรรม → สถานะเลือก/ยกเลิก
- ข้อมูลบันทึกอยู่ยาวนาน (ไม่หาย เมื่อปิดเบราว์เซอร์และเปิดใหม่)

### 2️⃣ ต้นแบบการติดตามปัจจัยสุขภาพการนอน (Sleep Health Tracking)

**ผู้ที่สร้าง:** Danudet (@Danudet888)

**ไฟล์ที่มี:**
- `Danudet_SleepHealthTracking_prototype.html.html` (168 บรรทัด)
- `Danudet_SleepHealthTracking_style.css` (154 บรรทัด)
- `Danudet_SleepHealthTracking_script.js` (script handler)

**ไหว้กำ (User Story):**
> ปุ๊ก (ผู้ใช้ที่มีปัญหาการนอน กระหมี่การตลาด) ต้องการบันทึกปัจจัยรายวัน เช่น การดื่มกาแฟ ความเครียด การออกกำลังกาย เวลานอน เพื่อให้เข้าใจว่าอะไรส่งผลต่อคุณภาพการนอนของเธอ

**คุณสมบัติที่ทำขึ้นมา:**
- ✅ **แบบฟอร์มด้านซ้าย** สำหรับบันทึกพฤติกรรมรายวัน:
  - กำหนดการดื่มกาแฟ (ไม่ / 1 แก้ว / 2 แก้ว / 3+ แก้ว)
  - เลื่อนระดับความเครียด (1-10)
  - เลือกการออกกำลังกาย (ไม่มี / เบา / ปานกลาง / หนัก)
  - กำหนดเวลาเข้านอน
  
- ✅ **แบบแท็บด้านขวา** แสดงประวัติและการวิเคราะห์:
  - **แท็บที่ 1 — ประวัติ:** แสดงข้อมูลที่บันทึกไว้ในตารางอ่านง่าย
  - **แท็บที่ 2 — การวิเคราะห์:** แสดงคะแนนคุณภาพการนอน (82/100) + คำแนะนำ

**ความเป็นโต้ตอบ (Interactivity):**
- เลื่อนความเครียด → ตัวเลขอัปเดตทันที
- กดปุ่มแท็บ → เนื้อหาเปลี่ยน
- บันทึกแบบฟอร์ม → เพิ่มแถวใหม่ในตาราง
- คะแนน = ฮาร์ดโค้ด (82/100) ยังไม่ใช่ของจริง

### 3️⃣ ต้นแบบหน้าแสดงผลข้อมูลการนอน (Dashboard Overview)

**ผู้ที่สร้าง:** Rungrawi (@lowkeyraining)

**ไฟล์ที่มี:**
- `rungrawi_dashboard_prototype.html` (120 บรรทัด)
- `rungrawi_dashboard_prototype.css` (77+ บรรทัด)
- `rungrawi_dashbord_prototype_script.js` (JavaScript handler)

**ไหว้กำ (User Story):**
> ผู้ใช้ที่ใส่ใจ ต้องการเห็นคะแนนคุณภาพการนอน แนวโน้มรายสัปดาห์ และคำแนะนำที่ทำให้เข้าใจในภาพรวม เพื่อกระตุ้นตัวเองให้นอนดีขึ้น

**คุณสมบัติที่ทำขึ้นมา:**
- ✅ **เมนูด้านข้าง (Sidebar)** พร้อม 5 หมวดหลัก:
  - 🏠 ภาพรวม
  - 📝 บันทึกการนอน
  - 📊 ประวัติ
  - 📈 รายงาน
  - 👤 โปรไฟล์
  
- ✅ **ส่วนหัด (Topbar):** 
  - ข้อความทักษยา (เช่น "สวัสดีตอนเช้า")
  - วันที่วันนี้
  - ปุ่มรีเฟรช

- ✅ **ส่วนหลัก (Main Content):**
  - การ์ดคะแนนคุณภาพการนอน (เช่น 82/100) พร้อมวงแหวนแสดงผล
  - ส่วนแจ้งเตือน "ยังไม่ได้บันทึกวันนี้" + ปุ่มบันทึก
  - สถิติปรากฏ:
    - เฉลี่ย 7 วัน
    - ต่อเนื่อง (เข้านอนติดต่อกี่วัน)
    - เวลาเข้านอนเฉลี่ย
    - เวลาตื่นเฉลี่ย
  - กราฟแท่งแสดงคะแนนการนอนรายวัน (กดได้)
  - ส่วนข้อสังเกต: "ความเครียดปานกลาง + ไม่ดื่มกาแฟ → การนอนที่ดี"

- ✅ **ตกแต่ง:**
  - ธีมสีเข้ม (น้ำเงินเข้ม + ลาเวนเดอร์)
  - อนิเมชั่นหิ่งห้อม반ะ
  - ไอคอนที่สวยงาม (จาก Lucide library)

**ความเป็นโต้ตอบ (Interactivity):**
- คลิกปุ่มเมนู → เปลี่ยนหมวด
- คลิกปุ่มรีเฟรช → อัปเดตข้อมูล
- คลิกแท่งกราฟ → แสดงรายละเอียดคืนที่เลือก
- การแจ้งเตือน (Toast) ปรากฏเมื่อ submit

## 🔄 การตัดสินใจ: Prototype vs Tracer Bullet

### ทีมตัดสินใจ: **ทั้ง 3 ต้นแบบคือ PROTOTYPE** 🎯

#### ความหมายของทั้ง 2 แบบ:

| หัวข้อ | **PROTOTYPE** (ต้นแบบทิ้งได้) | **TRACER BULLET** (ลูกศรสอด) |
|--------|------|------|
| **วัตถุประสงค์** | เรียนรู้และตรวจสอบ UX/UI ให้ถูกต้องก่อน | สร้างรากฐาน → ขยายโปรแกรมค่อย ๆ |
| **อายุการใช้** | สั้นมาก (วัน ไม่กี่วัน) | นาน (สัปดาห์ เดือน) |
| **คุณภาพโค้ด** | เขียนเร็ว ไม่สนใจมาตรฐาน | ต้องเป็นเกรด Production |
| **ที่เก็บข้อมูล** | Mock/localStorage | ฐานข้อมูลจริง + API |
| **ลบทิ้งได้ไหม** | **ใช่** → หลังจาก review ก็ทิ้ง | **ไม่** → ยังใช้ต่อใน Sprint ถัดไป |

### 🎯 เหตุผลเลือก PROTOTYPE สำหรับทั้ง 3:

| ต้นแบบ | เหตุผลที่เป็น PROTOTYPE |
|------|---|
| **Sleep Goal Setup** | ❌ ไม่มี backend API ❌ ใช้ localStorage เท่านั้น ❌ ไม่มี validation ที่เข้มงวด ❌ หลังรับ feedback ทีมจะเขียนใหม่ เพื่อต่อเชื่อมกับแอป |
| **Health Tracking** | ❌ คะแนนการนอน hardcoded (ไม่ใช่คำนวณจากอัลกอริทึม ML จริง) ❌ ข้อมูลหายเมื่อ refresh ❌ ไม่มี error handling ❌ อัลกอริทึมคำนวณจริงยังทำไม่ได้ |
| **Dashboard** | ❌ ข้อมูลทั้งหมดปลอม (mock) ❌ ปุ่มเมนูไม่เชื่อมกับหน้าจริง ❌ สถิติไม่มาจากฐานข้อมูล ❌ ใช้เพื่อทดสอบการออกแบบ layout แล้วจะเขียนใหม่ด้วย backend จริง |

---

### ❌ เหตุผลที่ไม่เป็น TRACER BULLET:

| ต้นแบบ | ทำไมไม่ใช่ Tracer Bullet |
|------|---|
| **Sleep Goal Setup** | 🚫 ไม่มี architecture pattern end-to-end (ไม่มี API route) 🚫 ไม่สามารถขยายต่อได้ง่าย (ต้องเขียน backend จากศูนย์) |
| **Health Tracking** | 🚫 อัลกอริทึมคะแนน placeholder → ไม่จริง 🚫 ไม่มี persistence ข้ามเซশัน 🚫 ไม่ follow production pattern |
| **Dashboard** | 🚫 ข้อมูลปลอมทั้งหมด → ไม่ใช่ real flow 🚫 ไม่ได้สอดสัญญาสถาปัตยกรรม 🚫 ทำให้เรียนรู้ layout แต่ไม่ได้เรียนรู้ data flow ที่จริง |

## ✅ สิ่งที่ทำขึ้นมา

| ด้าน | รายละเอียด |
|-----|---------|
| **HTML** | ใช้ semantic tags (header, aside, main, section, form, table) ที่ถูกต้อง |
| **CSS** | เขียนเอง ไม่ใช้ Bootstrap/Tailwind ให้ศึกษาการออกแบบ |
| **JavaScript** | โต้ตอบได้จริง (submit form, switch tab, localStorage, animation) |
| **ตามอุปกรณ์** | Prototype ตั้ง desktop-first ยังไม่ responsive สำหรับมือถือ |
| **ความเข้าถึง** | ใช้ semantic HTML บางส่วน สำหรับการอ่านโดยโปรแกรมจำหน่ายคน |

## ❌ สิ่งที่ไม่ได้ทำ (เพราะเป็น PROTOTYPE)

| ฟีเจอร์ | ทำไมไม่ทำ | ว่างนี้จะทำเมื่อไร |
|--------|---------|--------|
| **ตรวจสอบข้อมูล (Validation)** | Prototype ไม่ต้องเข้มงวด | Sprint 2 |
| **การเข้าสู่ระบบ (Authentication)** | ผู้ใช้เก็บค่าตายตัว | Sprint 3 |

| **ใช้ได้บนมือถือ (Responsive)** | Desktop-first; เพิ่ม media queries ทีหลัง | Sprint 2 |
| **สลับโหมดสว่าง/มืด (Theme Toggle)** | Dashboard ทำมืดเฉพาะ | Sprint 2 |

| **จัดการข้อผิดพลาด (Error Handling)** | ไม่มี error message ตรวจสอบ | Sprint 2 |
