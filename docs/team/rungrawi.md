**Broken Window ที่เคยเจอ**

* **Window คืออะไร:** ในโปรเจกต์ที่ผ่านมา เคยละเลยไม่จัดระเบียบโครงสร้างโฟลเดอร์ และตั้งชื่อตัวแปรแบบลวกๆ เพราะต้องรีบส่งงาน
* **ผลกระทบ:** พอคนอื่นในทีมมาดึงโค้ดไปทำต่อ เกิดความสับสนว่าข้อมูลแต่ละส่วนส่งต่อกันอย่างไร ทำให้ต่างคนต่างเขียนโค้ดแทรกทับลงไปเรื่อยๆ จนเกิดบัคอยู่บ่อยครั้งและใช้เวลาแก้โค้ดยาวนานขึ้น
* **ถ้าแก้ทันทีจะป้องกันอะไร:** หากมีการกำหนด Code standard, ประกาศ Data types/Interfaces ให้รัดกุม ตั้งแต่แรกและทำความสะอาดโค้ดตั้งแต่จุดที่มันเริ่มเละตั้งแต่ชิ้นแรก จะป้องกันไม่ให้ทีมเขียนโค้ดแบบทางลัดตาม และลด Technical Debt ที่ต้องมาตามแก้ย้อนหลังได้อย่างมหาศาล
