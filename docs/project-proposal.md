# Project: Good Night
> The Quantified Self Dashboard • Sleep Tracking & Optimization

---

## [ Theme ]
* **Selected Theme:** The Quantified Self Dashboard
* **Reason:** การนอนหลับส่งผลโดยตรงต่อสุขภาพและขีดความสามารถในการทำงาน การเปลี่ยนพฤติกรรมการนอนและข้อมูลทางชีวภาพให้กลายเป็น Visual Dashboard จะช่วยให้ผู้ใช้เห็นความสัมพันธ์ของปัจจัยต่าง ๆ และปรับสุขอนามัยการนอนได้อย่างมีหลักการ

---

## [ Target Persona ]
* **Name & Role:** คุณปณิธาน "ต้น" วงศ์สุวรรณ — *Health-Optimizing User (Age: 34, Product Manager)*
* **Context:** ต้นเป็นคนที่หลายคนมองว่า "ชีวิตดีอยู่แล้ว" — มีงานที่มั่นคง สุขภาพโดยรวมไม่มีปัญหาอะไรร้ายแรง นอนหลับได้ประมาณ 6-7 ชั่วโมงต่อคืน ไม่มีอาการนอนไม่หลับเรื้อรังหรือ sleep apnea แต่สิ่งที่ทำให้ต้นแตกต่างจากคนทั่วไปคือ mindset แบบ "preventive optimization" เขาเติบโตมาในครอบครัวที่พ่อเป็นโรคหัวใจตอนอายุ 50 กว่า ทำให้ต้นตระหนักตั้งแต่อายุ 30 ว่าสุขภาพคือการลงทุนระยะยาว ไม่ใช่เรื่องที่รอให้ป่วยก่อนแล้วค่อยแก้

เขาเริ่มออกกำลังกายสม่ำเสมอ ควบคุมอาหารคร่าวๆ และตอนนี้กำลังมองหาว่า "การนอน" ซึ่งเป็นตัวแปรสุดท้ายที่เขายังไม่เคยจัดการอย่างเป็นระบบ จะช่วยเพิ่ม performance ทั้งในชีวิตการทำงานและครอบครัวได้อย่างไร

---

## [ Value Proposition ]
แก้ปัญหาการนอนหลับไม่มีคุณภาพและการไม่รู้สาเหตุของความเหนื่อยล้าสะสม โดยระบบ **Good Night** ช่วยเปลี่ยนข้อมูลการนอนที่กระจัดกระจายให้กลายเป็น Data Visualization ที่เข้าใจง่าย ทำให้ผู้ใช้สามารถระบุปัจจัยรบกวน ปรับสุขอนามัยการนอนได้ตรงจุด และฟื้นฟูพลังงานในแต่ละวันได้อย่างเต็มประสิทธิภาพ

---

## [ MoSCoW Priorities ]

### Must Have
* ระบบบันทึกเวลาเข้านอน–ตื่นนอน พร้อมประเมินคุณภาพการนอน (Sleep Log & Quality Rating)
* หน้า Dashboard แสดงสถิติและกราฟแนวโน้มการนอนรายสัปดาห์/รายเดือน (Sleep Trends Visualization)

### Should Have
* ระบบแท็กปัจจัยพฤติกรรมประจำวัน (เช่น การดื่มคาเฟอีน, การออกกำลังกาย, Screen Time ก่อนนอน) เพื่อเปรียบเทียบผลกระทบต่อคุณภาพการนอน

### Could Have
* ระบบแจ้งเตือนเวลาเตรียมตัวเข้านอน (Bedtime Reminder) และฟังก์ชันคำนวณรอบการนอน (Sleep Cycle Calculator)

### Won't Have (This Term)
* การเชื่อมต่อและซิงค์ข้อมูลอัตโนมัติจาก Smartwatch/Hardware ภายนอกแบบ Real-time (เน้นพัฒนา Core Web Dashboard ก่อน)

---

## [ Risks & Assumptions ]
* **Assumptions (สมมติฐานที่ต้อง Validate):** ผู้ใช้งานมีวินัยเพียงพอที่จะเข้ามาบันทึก (Manual Log) ข้อมูลการนอนและปัจจัยต่าง ๆ อย่างสม่ำเสมอโดยไม่ต้องพึ่งพาเซนเซอร์อัตโนมัติ
* **Risks (ความเสี่ยงที่อาจเจอ):** 
  * *High Friction:* ผู้ใช้อาจรู้สึกลำบากในการกรอกข้อมูลทุกวันจนเลิกใช้งาน ส่งผลให้ชุดข้อมูลบน Dashboard ขาดความต่อเนื่อง
  * *Subjective Data Inaccuracy:* ข้อมูลที่บันทึกอาจคลาดเคลื่อนเนื่องจากเป็นการประเมินความรู้สึกของตัวผู้ใช้งานเอง
